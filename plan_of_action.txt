## 2. Step-by-Step Flow of Work

### 🔹 Phase 1: Backend & Model Training (Python + FastAPI)
1. **Model Training Pipeline (`train.py`):**
   - Reads `data_source_excel/height-weight.csv`.
   - Performs `train_test_split(test_size=0.25, random_state=42)` (matching your notebook).
   - Fits `StandardScaler` on $X_{train}$ and transforms both train and test sets.
   - Fits `LinearRegression()`.
   - Evaluates performance metrics: $R^2$, Adjusted $R^2$, MAE, MSE, RMSE, and Pearson correlation ($r$).
   - Saves production artifacts:
     - `scaler.joblib`
     - `model.joblib`
     - `model_metadata.json` (contains metrics and raw data points for visualization).

2. **Production API (`main.py`):**
   - Built using **FastAPI** with CORS enabled.
   - **`POST /predict`**: Accepts `{"weight": 75.0}` (with Pydantic validation: weight must be between 20 kg and 300 kg).
     - Returns:
       - `predicted_height_cm`: (e.g., `168.42`)
       - `predicted_height_ft_in`: (e.g., `5 ft 6.3 in`)
       - `z_score`: the standardized value used by the model
       - `formula_breakdown`: step-by-step calculation explanation
   - **`GET /metrics`**: Delivers model metrics ($R^2$, RMSE, MAE) and all data coordinates for dynamic chart plotting.
   - **`GET /health`**: Heartbeat endpoint.
   - **Interactive Swagger Docs (`/docs`)**: Interactive API testing UI generated automatically.

---

### 🔹 Phase 2: Frontend Application (Next.js + Modern UI)
1. **Design System & Aesthetics:**
   - **Dark glassmorphism theme**: Deep slate background (`#0B0F19`), neon cyan/emerald accents, soft borders, and smooth transitions.
   - **Typography**: Modern fonts (Inter / Outfit).
   - **Responsive**: Flawless on both mobile and desktop.

2. **Key UI Components:**
   - **Header & Status Bar:** Live status pill (`API: Online / Connected`), GitHub link, and LinkedIn badge.
   - **Interactive Predictor Card:**
     - Weight slider + direct number input (range: 30 kg to 140 kg).
     - Quick preset buttons (`50kg`, `70kg`, `85kg`, `100kg`).
     - Real-time Height display in **both cm** and **feet/inches**.
     - Visual human avatar / height scale graphic that dynamically adjusts.
   - **Interactive Regression Plot:**
     - Scatter points of the original 23 data samples.
     - The continuous **Best-Fit Regression Line**.
     - An active, glowing marker that slides along the line in real-time as you drag the weight slider!
   - **Model Insights & Metrics Grid:**
     - $R^2$ Score card (73.6% accuracy / variance explained).
     - Error cards: RMSE (10.72 cm) and MAE (9.67 cm).
     - Correlation meter ($r = 0.931$, strong direct relationship).
   - **"How It Works" Math Drawer:**
     - Explains the formula: $\text{Height} = \text{Intercept} + \text{Slope} \times \left(\frac{\text{Weight} - \mu}{\sigma}\right)$.
     - Explains why Standardization (Z-score) matters.
